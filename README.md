<h2>📌 Descripción del proyecto</h2>

<p>
Un portafolios dedicado para promocionar el servicio de comisiones de un amigo artista, implementando sus bocetos y su arte directamente en la página con una navegación interactiva.</p>

<p>
La página no está terminada a la espera de recibir material necesario para implementar dentro de la página, por lo que hasta ahora es únicamente un boceto.</p>

---

<h2>🛠️ Características principales</h2>

<ul>
  <li>HTML, CSS y JavaScript</li>
  <li>Diseño artístico y profesional</li>
  <li>Navegación a modo de diapositiva</li>
</ul>
